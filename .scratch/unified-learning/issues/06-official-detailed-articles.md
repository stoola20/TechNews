# 06: 官方文章 08:00 開始，全部詳細整理入庫

**What to build:** 既有官方來源在台灣時間 08:00 開始抓取，符合主題的文章由 Mac 詳細整理後進入共同文章庫；Telegram 介紹能連到詳細正文。

**Blocked by:** 02：網站分享純文字文章，經 Mac 產生詳細教材

**Status:** done

- [x] 官方內容保留背景、機制、例子、操作、限制，不因通知長度變短導讀
- [x] 來源範圍及主題篩選沿用
- [x] 官方排程不再誤依賴舊 Cron 字串
- [x] 積壓由背景續跑
- [x] 重複日次事件不重複生成
- [x] 主動分享同網址可重用且不被官方相關性篩選淘汰。

## 實作紀錄

- `src/schedule.js`：Cron 對任務的明確對照；`0 0 * * *`（台灣 08:00）開始官方、書籤日次與作者重查，`*/5` 只做維護，其他 Cron 字串不觸發任何任務。
- `src/learning/official.js`：官方發現排入共同文章庫（receipt 與舊導讀搬移相同，重複事件冪等）；證據沿用官方擷取。
- 只有官方收件時，本機工作附上主題判斷；不符合者標為 `filtered`，不通知、預設列表隱藏；主動分享會解除篩選。
- 切換開關沿用 `learning:text`：本機模式才把官方文章送進文章庫，否則 08:00 跑舊導讀流程。
- 驗證：`tests/official.test.js`。
