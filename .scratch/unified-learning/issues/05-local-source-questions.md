# 05: 本機來源追問、進度與歷史

**What to build:** 使用者對單篇或整個文章庫提問，問題保存並交由 Mac 回答；可關閉頁面再回來查看進度、答案及可查核來源。

**Blocked by:** 02：網站分享純文字文章，經 Mac 產生詳細教材

**Status:** ready-for-agent

- [ ] 沿用關鍵字檢索，不新增模型／向量依賴
- [ ] 已保存文字及新舊媒體觀察可作證據
- [ ] 單篇範圍不越界
- [ ] 引用只來自實際提供片段
- [ ] 不足時明說
- [ ] 問題優先於背景生成，但不強制中斷在途推論
- [ ] 離線等待可恢復、歷史受登入保護、完成不發文章通知。
