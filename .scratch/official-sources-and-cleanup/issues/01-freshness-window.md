# 01: 官方來源只收 7 天內發表的文章

**What to build:** 官方來源只收發表 7 天內的文章。來源列表冒出的舊文章（RSS 一次放出更多歷史、流程交接留下的積壓）只記為看過，不收件、不通知。列表沒有日期的文章，抓到原文後以官方收件時間判斷，太舊就篩掉、不呼叫文字模型。分享與收藏不受限制。

**Blocked by:** None (can start immediately)

**Status:** done

- [x] 部署變數 `MAX_ARTICLE_AGE_DAYS`（預設 7）取代 `BACKFILL_DAYS`，新來源首次回補與每日發現共用
- [x] 發現時：有日期且超過期限的條目只記為看過，不收件
- [x] 抓到原文後：只來自官方、尚未通知的文章，發表早於收件時 N 天就設為 `filtered` 並寫原因，不呼叫模型、不通知
- [x] 以收件時間為準：收件後的處理延誤不會讓文章過期
- [x] 主動分享同一篇舊文照常整理
- [x] 舊流程 `/run` 套用同一期限，積壓的舊文標為略過
- [x] 修正寫死日期、會隨真實時間過期的測試

## 實作紀錄

- 驗證：官方發現測試涵蓋太舊略過、沒有日期時抓到原文後判斷、收件延誤不算過期、分享不受限；舊流程測試涵蓋積壓略過。三個新測試在修改前的程式上會失敗。
- 用真實 RSS 加上修改前的看過清單重播一次發現，舊文不再被收件，只留下期限內的文章。
