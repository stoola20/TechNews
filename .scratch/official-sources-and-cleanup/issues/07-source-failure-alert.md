# 07: 來源連續失敗提醒

**What to build:** 同一個官方來源連續兩天 08:00 都失敗時（包括列表抓不到任何文章），發一則 Telegram 提醒，寫出來源名稱、最近一次失敗原因與管理頁連結。恢復前不重發；恢復時不另外通知，下一次故障再重新提醒。

**Blocked by:** 04：管理頁「官方來源」區塊

**Status:** ready-for-agent

- [ ] 來源失敗時累計連續失敗次數，成功一次就歸零並清除已提醒狀態
- [ ] 次數達到 2 且尚未提醒時建立一則提醒；第三次以後不重發
- [ ] 提醒走既有的通知保存與送出機制，失敗只重送同一份；與文章通知的去重互不影響
- [ ] 提醒內容含來源名稱、失敗原因、管理頁連結
- [ ] 測試以注入時間模擬連續兩天失敗、第三天、恢復後再故障
