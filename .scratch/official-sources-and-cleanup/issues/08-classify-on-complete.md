# 08: 文章完成就分類，通知附主題

**What to build:** 文章寫成已完成或部分完成後，立刻用 Workers AI Gemma 4 分類，再建立通知。Telegram 完成通知與更新通知的第一行是主題標籤（主要主題，有次要主題時接在後面）。分類失敗時通知照常發出、不附主題，之後由維護排程重試。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Gemini 寫作完成與 Mac 執行器回報完成，兩條路徑都在建立通知前分類
- [ ] 分類提示詞、輸出驗證、手動主題優先的規則不變
- [ ] 通知第一行為主題標籤；主題名稱中不能出現在 hashtag 的字元換成底線
- [ ] 分類失敗時通知不等待、不附主題，失敗次數與延後重試照現有規則；之後重試成功
- [ ] 維護排程的分類步驟保留，處理重試、重新分類全部與未分類的既有文章
- [ ] 架構文件更新分類時機
