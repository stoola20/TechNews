# 05: 逐篇明細與「仍要收件」

**What to build:** 在官方來源區塊點開一個來源，看到最近 7 天首次看到的每篇文章：發表日、標題（連到原文）、處理結果。收件的連到文章庫那一篇；太舊略過的有「仍要收件」按鈕，按下後等同主動分享：不受主題篩選，完成後照常通知。

**Blocked by:** 04：管理頁「官方來源」區塊

**Status:** ready-for-agent

- [ ] 官方來源 API 回傳每個來源最近 7 天的條目
- [ ] 點開來源顯示逐篇明細；標題連原文，收件的連文章庫
- [ ] 「仍要收件」以分享入口收件，條目改為收件並標記為手動；完成後發通知
- [ ] 抓到原文後才被判定太舊、已在文章庫篩掉的文章，也能用「仍要收件」重新整理
- [ ] 重複按「仍要收件」不會建立第二篇或重複通知
- [ ] 來源說明文件補上「仍要收件」
