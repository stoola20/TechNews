**Blocked by:** 04：管理頁「官方來源」區塊

- [x] 點開來源顯示逐篇明細；標題連原文，收件的連文章庫

## 實作紀錄

- 官方來源 API 每個來源附上最近 7 天首次看到的條目（發表日、標題、處理結果、理由、文章庫連結），上限 200 筆。
- 管理頁在來源表下方逐來源展開明細；重新整理後保留原本展開的來源。收件的連到文章庫，太舊略過的有「仍要收件」按鈕。
- 「仍要收件」以分享入口收件（不受主題篩選與新鮮度期限），同時補上官方收件，讓原文沿用該來源的擷取規則；條目改為收件並標記手動，之後的發現與原文判定都不會改回太舊。收件代碼固定，重複按不新增收件或通知。沒有來源紀錄的網址回 400。
- 驗證：列表就判定太舊與抓到原文才判定太舊的兩種文章都能重新整理並通知，整理時不帶官方主題判斷；重複按不重複；內建瀏覽器實際按下按鈕並查看手機寬度。
