# 03: 測試可以指定「現在時間」

**What to build:** 文章庫 handler 的依賴可以提供 `now()`，沒有提供時用系統時間。官方發現、新鮮度期限與費用月份都從這裡取時間，測試可以假裝「今天是某一天」。後續的 30 天清理、連續兩天失敗、7 天明細都靠這個切入點測試。

**Blocked by:** 02：移除舊每日導讀流程

**Status:** done

- [x] handler 依賴可注入 `now()`，預設為系統時間
- [x] 官方發現、新鮮度判斷、收件時間、費用月份改用注入的時間
- [x] 既有的官方發現與新鮮度測試改成固定時間，不再依賴真實時鐘
- [x] 全部測試在不同的真實日期執行都會通過

## 實作紀錄

- 新增請求範圍的時鐘（`AsyncLocalStorage`）：handler 依賴提供 `now()` 時，該次請求、排程、佇列處理與 service 對外入口內的時間都從它取。伺服器端的時間戳、租約、重試時間、費用月份與 UTC 日都改讀這個時鐘；送到瀏覽器的頁面腳本不變。
- 官方發現與新鮮度測試改用固定的「現在時間」。
- 驗證：把系統時間平移 +400 天與 −30 天各跑一次全部測試，皆通過。
