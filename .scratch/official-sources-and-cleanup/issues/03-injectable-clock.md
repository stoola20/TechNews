# 03: 測試可以指定「現在時間」

**What to build:** 文章庫 handler 的依賴可以提供 `now()`，沒有提供時用系統時間。官方發現、新鮮度期限與費用月份都從這裡取時間，測試可以假裝「今天是某一天」。後續的 30 天清理、連續兩天失敗、7 天明細都靠這個切入點測試。

**Blocked by:** 02：移除舊每日導讀流程

**Status:** ready-for-agent

- [ ] handler 依賴可注入 `now()`，預設為系統時間
- [ ] 官方發現、新鮮度判斷、收件時間、費用月份改用注入的時間
- [ ] 既有的官方發現與新鮮度測試改成固定時間，不再依賴真實時鐘
- [ ] 全部測試在不同的真實日期執行都會通過
