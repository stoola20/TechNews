# 04: 管理頁「官方來源」區塊：每個來源最近一輪結果

**What to build:** 管理頁新增「官方來源」區塊，標題註明「只收 N 天內發表的文章」。每個來源一列，顯示最後檢查時間、最近一輪的找到／收件／太舊略過篇數，以及正常或失敗（含原因）。背後的「看過哪些網址」改成一個網址一列，每輪發現都留下紀錄，超過 30 天的自動清理。

**Blocked by:** 03：測試可以指定「現在時間」

**Status:** done

- [x] migration 把既有看過清單轉成初次基準條目；發現流程改用新表判斷是否看過

- [x] 每次官方發現，每個來源寫一筆執行紀錄：找到、收件、太舊略過、初次基準、成功或失敗與原因；列表抓不到任何文章算失敗

- [x] 管理頁區塊顯示每個來源一列，手機寬度可閱讀

## 實作紀錄

- migration 新增 `source_entries`（一個網址一列）與 `source_runs`（每輪每來源一筆），既有看過清單轉成初次基準；`seen_urls_json` 清空、不再寫入。
- 發現流程用 `source_entries` 判斷是否看過；仍在列表上的已知網址只更新最後出現時間（分批寫入，不超過 D1 綁定參數上限）。收件成功才記錄，失敗時下一輪重試。

- 維護排程清除 30 天前的執行紀錄，以及 30 天內都沒再出現在列表的條目。
- 管理頁「官方來源」區塊：每個來源一列；失敗的來源顯示原因，最後檢查時間取最近一次執行；手機寬度改成堆疊排列。順手把模型分工裡殘留的舊流程文字改掉。
