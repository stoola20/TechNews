# 04: 管理頁「官方來源」區塊：每個來源最近一輪結果

**What to build:** 管理頁新增「官方來源」區塊，標題註明「只收 N 天內發表的文章」。每個來源一列，顯示最後檢查時間、最近一輪的找到／收件／太舊略過篇數，以及正常或失敗（含原因）。背後的「看過哪些網址」改成一個網址一列，每輪發現都留下紀錄，超過 30 天的自動清理。

**Blocked by:** 03：測試可以指定「現在時間」

**Status:** ready-for-agent

- [ ] 新表記錄每個來源每個網址：首次看到、最後出現在列表、標題、發表時間、決策（初次基準／收件／太舊略過）、原因、對應文章
- [ ] migration 把既有看過清單轉成初次基準條目；發現流程改用新表判斷是否看過
- [ ] 抓到原文後才判定太舊的文章，對應條目也更新為太舊略過
- [ ] 每次官方發現，每個來源寫一筆執行紀錄：找到、收件、太舊略過、初次基準、成功或失敗與原因；列表抓不到任何文章算失敗
- [ ] 維護排程清理超過 30 天的執行紀錄，以及 30 天內都沒再出現在列表的條目；仍在列表上的網址不清除
- [ ] 讀取官方來源的 API 回傳期限天數與每個來源的最近一輪結果、狀態
- [ ] 管理頁區塊顯示每個來源一列，手機寬度可閱讀
- [ ] 架構文件補上來源紀錄的說明
