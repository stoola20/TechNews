# 06: 來源與主題設定併入管理頁

**What to build:** 原本在手機設定頁的「想收到的內容」與來源清單，搬到官方來源區塊。區塊上方是「想收到的內容」文字框；每個來源那一列有開關；收合的「進階：編輯來源 JSON」可以新增、修改、刪除來源。儲存後下一輪排程生效。關閉的來源不參與發現、不觸發失敗提醒，歷史紀錄保留並顯示「已關閉」。

**Blocked by:** 02：移除舊每日導讀流程；04：管理頁「官方來源」區塊

**Status:** ready-for-agent

- [ ] 來源設定每筆新增 `enabled`（預設 true），舊設定讀取時視為開啟
- [ ] 儲存設定 API 同時接收想收到的內容與來源清單；驗證規則沿用現有來源驗證，失敗回 400 且原設定不變
- [ ] 管理頁文字框、開關、進階 JSON 都能儲存並顯示結果
- [ ] 關閉的來源不發現、不寫執行紀錄、不累計失敗；列表顯示「已關閉」
- [ ] 官方文章的主題篩選使用新存的「想收到的內容」
- [ ] 設定文件改寫成用管理頁設定來源
