# 10: 未確認費用作廢，恢復按鈕只在暫停時出現

**What to build:** 管理頁預算區塊的每筆未確認費用都有「作廢」按鈕，必須填說明。作廢的費用不算進月預算，但列在「已作廢」明細，顯示時間、類別、金額與說明。升級時，既有的 X 未確認費用（失敗預留與重讀風險估算）全部作廢。「恢復處理」只在暫停時出現，旁邊顯示暫停原因與按下的效果；預算為 0 而無法恢復時，提示先作廢未確認費用或調整月預算。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 費用新增 `voided` 狀態；月預算已使用金額與預留檢查都排除 `voided`
- [ ] 作廢 API 只接受 `uncertain` 費用且必須附說明，記錄作廢時間與說明
- [ ] migration 把既有 `x`、`x-reread-risk` 的 `uncertain` 費用改為作廢並附升級說明；其他類別不動
- [ ] 預算區塊：未確認明細有作廢按鈕；新增「已作廢」合計與可展開明細
- [ ] 恢復按鈕只在暫停時顯示，附暫停原因與一句說明；未暫停時隱藏
- [ ] 預算為 0 時恢復失敗並顯示下一步提示
- [ ] 作廢後管理頁重新讀取預算與暫停狀態，不自動恢復
