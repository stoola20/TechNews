# 04: 主題表、Workers AI 自動分類與主題篩選

**What to build:** 文章庫有一份 7 個主題的預設主題表。維護排程用 Workers AI Gemma 4 讀標題與導讀，為已完成文章選出主要主題與最多 1 個次要主題；新文章數分鐘內分類，既有文章逐輪回補，內容更新後重新分類。列表頂端有附篇數的主題 chip（全部、各主題、未分類），每篇顯示主題顏色點與主題名稱。

**Blocked by:** 03：列表改版為緊湊清單（設計稿 B）

**Status:** ready-for-agent

- [ ] migration 新增主題相關欄位；預設主題表含固定識別碼、名稱、說明、顏色
- [ ] 維護排程每輪分類有限篇數，只處理符合條件（未分類、revision 變更、主題已不存在，且非手動）的文章
- [ ] 模型輸出不屬於主題表時視為失敗，累計次數並延後重試；失敗不影響文章其他功能，也不記入預算、不發通知
- [ ] `GET topics` 回傳各主題與未分類篇數，篇數依其他篩選條件計算
- [ ] `GET items?topic=` 比對主要與次要主題，可與搜尋、未讀、管理篩選並用，選擇保存在網址
- [ ] 列表項目與閱讀頁顯示主題；chip 在手機寬度可橫向捲動
