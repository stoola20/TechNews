# 01: X 書籤同步與作者重查改由管理頁切換

**What to build:** 管理頁的 X 同步區塊有「書籤同步」與「作者重查」兩個開關，設定保存在資料庫，切換後立即生效。沒有設定時兩者都關閉。部署設定不再使用環境變數。手動分享 X 連結不受影響。

**Blocked by:** None (can start immediately)

**Status:** done

- [x] 沒有設定時，書籤局部檢查、每日完整核對、續跑、手動同步、X 授權回呼都不讀 X 書籤；作者重查不執行
- [x] 管理頁開啟書籤同步後，排程與手動同步恢復既有行為；開啟作者重查後恢復 24 小時重查
- [x] 狀態 API 回傳兩個開關；管理頁顯示目前狀態並可切換
- [x] 手動分享 X 連結仍正常取得與整理
- [x] 移除部署設定中的兩個環境變數，設定文件改寫為管理頁操作

## 實作紀錄

- 開關存在 settings 的 `learning:x-reads`（`bookmarks`、`author_recheck`），未設定時都是 `false`；`PUT api/admin/x-reads` 只接受布林值。
- 書籤同步的所有入口仍經過同一個判斷；狀態 API 改回傳 `x_reads`。
- 驗證：`tests/bookmark-sync.test.js`「X 讀取開關預設關閉」案例；其他同步測試改為先打開開關。
