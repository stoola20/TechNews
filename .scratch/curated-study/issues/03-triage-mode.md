# 03: 一次一篇的篩選模式

**What to build:** `?view=triage` 一次顯示一篇待決定文章的標題、主題、發布者、發表日、剩餘天數與導讀；待回補書籤顯示保存的原文預覽。用按鈕或鍵盤選擇保留（K）、保留並 ★（S）、刪除（D）、略過（J／→）、復原上一篇（U），決定後換下一篇並更新剩餘篇數。

**Blocked by:** 01：篩選結果、最近刪除與列表檢視

**Status:** done

- [x] 只列可閱讀的待決定文章（`ready`、`partial`、`awaiting_backfill`），順序與列表預設相同
- [x] 卡片有「開啟全文」；待回補文章顯示主要原文前 600 字
- [x] 按鍵只在篩選模式有效，焦點在輸入框時不觸發；? 顯示按鍵說明
- [x] 略過只在這次瀏覽跳過，不改狀態；復原上一篇還原上一個決定
- [x] 待回補文章按保留或 ★ 時開始整理
- [x] 清空時顯示「待決定已清空」與回到列表的連結
- [x] 內建瀏覽器在桌機與手機寬度用按鈕與鍵盤實際篩選
