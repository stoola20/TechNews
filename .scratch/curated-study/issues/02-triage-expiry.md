# 02: 待決定 14 天自動移到最近刪除

**What to build:** 文章第一次可以閱讀（完成整理或進入待回補）時，若是待決定，設定 14 天期限。維護排程把逾期仍待決定的文章移到最近刪除，原因標示為逾期。升級前已在文章庫的文章不套用。篩選卡片與閱讀頁顯示剩餘天數。

**Blocked by:** 01：篩選結果、最近刪除與列表檢視

**Status:** done

- [x] 期限只在第一次可閱讀時設定，之後的重寫與更新不重設；升級時仍在處理中的文章完成時一樣設定
- [x] 處理中、等待本機、費用暫停的文章不計時
- [x] 維護排程依索引挑出逾期文章，移到最近刪除並記原因 `expired`，每輪有篇數上限
- [x] 最近刪除中的文章被手動分享時，期限重設為 14 天
- [x] 閱讀頁顯示待決定文章的剩餘天數；最近刪除區分手動與逾期
- [x] 測試用注入的 `now()` 驗證起算點與逾期
