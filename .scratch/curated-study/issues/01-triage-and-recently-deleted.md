# 01: 篩選結果、最近刪除與列表檢視

**What to build:** 每篇文章有待決定、保留、刪除三種篩選結果，★ 是保留裡的常用參考。升級時既有文章全部設為待決定。列表預設只顯示保留文章，可以切換保留、★、待決定、全部、最近刪除，頂端顯示「待決定 N 篇」。閱讀頁有保留、★、刪除按鈕。刪除先進最近刪除，7 天內可復原，第 8 天由維護排程清除，只留網址紀錄。等待確認回補的書籤改用同一套刪除。列表搜尋加上比對筆記。

**Blocked by:** None (can start immediately)

**Status:** done

- [x] migration 新增篩選欄位與索引；既有文章設為 `pending`，升級時已可閱讀的文章標記為不套用自動過期
- [x] `PUT items/:id/triage` 支援 `keep`、`star`、`unstar`、`pending`、`delete`、`restore`；★ 與保留的連動正確；待回補文章保留時同時啟動整理
- [x] 移除只限待回補的 `DELETE items/:id`，待回補文章的刪除改進最近刪除
- [x] `GET items` 與 `GET topics` 支援 `triage` 參數（預設 `kept`），`all` 不含最近刪除；主題篇數依同一組條件計算
- [x] `GET status` 回傳待決定篇數；列表頂端顯示入口；★ 文章在列表上有星號
- [x] 最近刪除檢視顯示剩餘天數、刪除原因與復原；復原回到刪除前的結果

- [x] 最近刪除與已清除的文章不建立通知，已排入的通知送出前略過
- [x] 列表搜尋比對筆記
