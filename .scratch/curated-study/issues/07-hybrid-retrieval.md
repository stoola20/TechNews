# 07: 混合檢索與全庫追問改版

**What to build:** 獨立的檢索模組：語意（Vectorize）加 D1 關鍵字，用 RRF 合併，只回保留文章；範圍 `all` 另用關鍵字補上待決定文章並標示未保留。語意檢索失敗時退回關鍵字並標示降級。全庫追問改用這個模組，預設只查保留，問答區可勾「也查未保留」。

**Blocked by:** 06：保留文章的 RAG 索引

**Status:** ready-for-agent

- [ ] 對外只有一個檢索介面，片段格式沿用現有追問並標示是否保留
- [ ] 語意取前 30 筆、丟掉低於門檻與已非保留的片段；關鍵字限定保留文章；RRF 每份貢獻 1／(10＋名次)；每篇最多 3 段，取前 12 段
- [ ] 範圍 `all` 補上待決定文章（不含最近刪除），排在保留之後
- [ ] Workers AI 或 Vectorize 失敗時回傳 `degraded`，畫面顯示「這次只比對關鍵字」
- [ ] `POST ask` 新增 `include_unkept`；本機工作的輸入沿用同一份片段；單篇追問不變
- [ ] 回答出處標示保留或未保留
- [ ] 測試涵蓋中英混合查詢、精確詞、合併順序、範圍與降級
