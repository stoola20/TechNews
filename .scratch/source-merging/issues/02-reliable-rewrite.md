# 02: 可靠的逐篇重寫

**What to build:** 舊官方導讀按「只重寫文字」能穩定改成詳細教材：純文字文章不因 Gemini 多回傳的媒體觀察失敗，缺原文時自動重抓官方原文，確認時寫出使用的模型。

**Blocked by:** 01：頁內確認對話框

**Status:** done

- [x] 沒有媒體時忽略 Gemini 觀察，不視為錯誤
- [x] 舊導讀沒有保存原文時，重寫先重抓官方公開原文；失敗如實列缺漏
- [x] 重寫與補缺漏的確認文字含目前文字模型名稱

## 實作紀錄

- 成因：Gemini 對沒有媒體的純文字來源仍可能回傳 `observations`，原驗證會以「媒體觀察缺少有效來源與說明」拒絕，重試三次後停在「需要處理」。`src/learning/gemini.js` 在沒有媒體時直接清空觀察。
- 舊導讀缺原文：既有 `acquireEvidence` 在沒有可用主來源時，會依官方收件紀錄的來源設定重抓公開原文；新增測試鎖定這個行為，並確認舊的「未保存原文」缺漏在重寫後消失。
- `GET /learning/api/status` 的 `local.text_model` 回報目前文字模型；重寫、補缺漏的確認文字與舊導讀提示都寫出模型名稱。
- 驗證：`tests/library.test.js`「舊導讀重寫」案例。
