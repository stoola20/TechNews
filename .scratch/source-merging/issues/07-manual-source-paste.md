# 07: 手動貼上缺漏原文

**What to build:** 自動取得失敗的來源，可在文章頁貼上原文，保存為該網址的使用者提供來源後重新整理。

**Blocked by:** 01：頁內確認對話框

**Status:** done

- [x] 只接受目前列為缺漏的網址
- [x] 來源標示為使用者提供，與自動取得的來源區分
- [x] 貼上後缺漏消失並排入整理；之後的補缺漏不覆蓋使用者提供的內容

## 實作紀錄

- `POST /learning/api/items/:id/source`（`{url, content}`）：只接受目前狀態為缺漏、關係為主要來源或外部文章的網址；內容需 20 到 200,000 字（此路由請求上限 1 MB）。直接把那列缺漏改為可用並標 `provided_by: user`，文章重新排入整理。
- `saveEvidence` 遇到使用者提供的來源時不覆蓋，之後「補取缺漏」不論成功或失敗都保留貼上的內容。
- 文章頁「來源與處理提醒」中可貼上的缺漏旁有「貼上原文」按鈕，開啟頁內輸入對話框；原始來源區標示「你貼上的原文」。
- 驗證：`tests/library-ui.test.js`；示範伺服器的「來源有缺漏的示範」以內建瀏覽器實際貼上，重新整理後缺漏消失並改為已完成。
