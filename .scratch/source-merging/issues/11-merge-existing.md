# 11: 既有重複一次合併

**What to build:** 掃描既有文章，把符合合併條件的重複項一次合併，保留較完整的一篇。

**Blocked by:** 10：X 貼文與外部文章合併

**Status:** done（待部署後由維護排程執行）

- [x] 詳細版優先於舊短導讀；同為詳細版保留含 X 貼文者
- [x] 不呼叫模型或外部 API、不發通知
- [x] 可重複執行、結果不變；舊 ID 仍可開啟

## 實作紀錄

- `mergeExistingDuplicates`（`src/learning/linking.js`）：掃描尚未檢查的已整理 X 文章，計算唯一外連；文章庫已有同網址文章時，把那篇併入 X 文章（保留含貼文與外部全文的一篇），筆記、已讀、收件與別名一併移過來。檢查後寫入 `linked_url`（沒有唯一外連時寫空字串），之後不再重算。
- 每五分鐘維護排程在搬移舊資料後執行；管理頁「搬移舊官方導讀」也會一起執行。另在維護時清掉只因外部裝飾圖片而標成缺漏的舊文章狀態。
- 併入的收件紀錄 `notify_revision` 不超過 X 文章目前版本，避免之後的更新被誤判為已通知。
- 驗證：`tests/linking.test.js`「既有重複一次合併」。對正式資料做唯讀試算：預計合併 1 組（X 詳細版＋官方舊導讀），未寫入任何資料。
