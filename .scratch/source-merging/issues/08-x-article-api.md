# 08: X 長文經 API 取得

**What to build:** 以一次真實 X API 讀取確認貼文欄位能否取得 X 長文全文；可以則在讀取貼文時帶入長文正文，不再列為缺漏。

**Blocked by:** 無

**Status:** blocked（正式環境 X 授權需重新連接）

- [ ] 真實讀取只記錄欄位可用與否的結論，不保存內容與帳號資訊
- [ ] 可用時解析長文並以合成回應測試
- [ ] 不可用時記錄結論，交由 09 處理

## 進度

- 本機只能在 access token 仍有效時讀取，不做 refresh（避免換掉正式環境保存的 refresh token；本機也沒有 X client 金鑰）。實測時 token 已過期約兩小時，書籤局部檢查也停在「請查看 X 授權或設定」，因此尚未發出任何 X API 請求。
- 不在未驗證前把未知欄位加進貼文請求：欄位名稱錯誤會讓 X 回 400，連帶使所有貼文讀取失敗。
- 下一步：使用者在管理頁重新連接 X 後兩小時內，以一次貼文讀取確認長文欄位。可用就在讀取貼文時帶入長文；不可用則維持 09 的 Mac 代抓與 07 的手動貼上。
