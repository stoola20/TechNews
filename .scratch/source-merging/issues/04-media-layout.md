# 04: 媒體與說明相鄰、閱讀頁順序

**What to build:** 每支影片／每張圖下方緊接它自己的時間點與內容，不帶多餘標籤；閱讀頁順序改為教材、媒體、舊版本、原始來源（最下方）。

**Blocked by:** 01：頁內確認對話框

**Status:** done

- [x] Gemini 觀察可對應單一媒體；舊資料依所屬貼文分組
- [x] 說明只顯示時間點按鈕與內容
- [x] 原始來源與片段在頁面最下方
- [x] 內建瀏覽器實際檢查兩支影片的文章

## 實作紀錄

- `src/learning/page.js`：每個媒體包成一組，下方緊接它自己的說明；每行只有時間點按鈕（有時間點時）與內容。Gemini 觀察有 `media_id` 時對應單一媒體；舊資料只有貼文 ID，放在該貼文最後一個媒體之下。本機路徑的媒體證據也拿掉「媒體證據（模型觀察）」「畫面：」標籤，只保留「推論：」以區分推論與觀察。
- 閱讀頁順序改為教材 → 媒體與時間點 → 舊版本 → 原始來源與片段。
- `src/learning/gemini.js`：提示附上每個媒體的 ID，輸出 schema 新增 `media_id`；對不上的值清空，不讓整篇失敗。
- 舊資料中的外部網頁裝飾圖片：`skipDecorative` 在整理與開啟文章時標成 `decorative`，不下載、不解析、不顯示，並從文章缺漏移除；沒有其他缺漏時文章改回已完成。開啟文章時同步列表上的狀態徽章。
- 驗證：`tests/learning.test.js`（media_id）、`tests/library-ui.test.js`（裝飾圖片與缺漏）；示範伺服器新增「兩支影片與逐段說明」合成文章，以內建瀏覽器確認兩支影片各自緊接說明、logo 與其缺漏不出現、原始來源在最下方。
