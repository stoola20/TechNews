# 統一整理流程：實作計畫與工作票

**Status:** approved — 使用者已確認 12 張 tickets 的粒度與阻擋關係，工作票已個別發布為 ready-for-agent。

規格見 [統一詳細整理、本機文字模型與桌機文章庫](../specs/unified-learning.md)。本文件記錄已核准的實作拆分；工作票發布不代表功能已實作、模型已驗收或已部署。

## 順序與邊界

先以相容擴充把兩套既有文章接到共同閱讀與身分，再接通本機文字這條完整路徑。媒體、官方文章、追問、費用及通知各自接入；桌機閱讀可從共同文章庫完成後開始，不必等待本機流程全部完成。

每張票涵蓋足以展示的資料、行為、介面與驗證，不單獨拆資料表、API 或 UI。重疊修改同一模組不等於需求上的阻擋；最後以整合驗收確認各條路徑共同運作。

## Tickets

### 01：共同文章庫與既有資料相容搬移

**Blocked by:** None（可立即開始）。

**What it delivers:** 原本分散的官方文章與收藏出現在同一私人文章庫，保留來源身分、原文、既有結果、筆記、已讀及舊連結，不觸發生成或通知。

**驗收：** 合成的兩套舊資料可重複搬移而不新增副本；同網址合併收件／版本，保留收藏正文與閱讀資料；X 與外連文章不誤合併；短導讀及缺失資料如實標示；未登入無法讀取。相容演進期間既有寫入仍可讀取，原流程回歸通過。

### 02：網站分享純文字文章，經 Mac 產生詳細教材

**Blocked by:** 01。

**What it delivers:** 網站加入一篇純文字文章，雲端保存來源與工作，Mac 經專用憑證主動領取、使用原生 Ollama Gemma、驗證並回報，使用者能在文章庫讀完整內容與來源。

**驗收：** 基本領取／續約／回報契約、輸入與 attempt 身分及單工限制成立；重複連結重用同篇；完整來源尾端有進模型；詳細正文、引用、模型資訊及介紹保存；未完成或無效模型輸出不標完成；純文字不呼叫 Flash；本機離線顯示等待；新路徑受切換設定控制，現有正式路徑尚可運作。

### 03：Mac 常駐、離線續跑與處理狀態

**Blocked by:** 02。

**What it delivers:** 執行器能常駐與重新啟動；網站看得出 Mac 是否在線、文章卡在哪一階段，中斷後接續且不被過期結果覆寫。

**驗收：** 健康與最後心跳、長工作續約、斷線重啟、工作重新領取、舊 attempt／舊輸入回報拒絕及回報重播冪等皆可操作驗證；等待本機不累加模型失敗；只重跑未完成階段；有啟停／自啟動說明；不暴露 Ollama、不觸發雲端 fallback；排隊優先級與背景公平性可觀察。

### 04：Flash 媒體證據接力 Gemma 詳細整理

**Blocked by:** 02。

**What it delivers:** 一篇含圖片或影片的 X 內容，由 Flash 先保存可查核媒體證據，再由 Mac Gemma 結合原文完成詳細教材，閱讀頁可核對來源及時間點。

**驗收：** OCR、可辨識語音、畫面觀察、時間點與缺口符合證據契約；不能只以短 observation 冒充完整解析；無效來源／超片長時間點被拒絕；文字重試重用已保存媒體結果；超限及到期顯示缺漏並沿用保存政策；主動分享與現有來源取得路徑不回歸。

### 05：本機來源追問、進度與歷史

**Blocked by:** 02。

**What it delivers:** 使用者對單篇或整個文章庫提問，問題保存並交由 Mac 回答；可關閉頁面再回來查看進度、答案及可查核來源。

**驗收：** 沿用關鍵字檢索，不新增模型／向量依賴；已保存文字及新舊媒體觀察可作證據；單篇範圍不越界；引用只來自實際提供片段；不足時明說；問題優先於背景生成，但不強制中斷在途推論；離線等待可恢復、歷史受登入保護、完成不發文章通知。

### 06：官方文章 08:00 開始，全部詳細整理入庫

**Blocked by:** 02。

**What it delivers:** 既有官方來源在台灣時間 08:00 開始抓取，符合主題的文章由 Mac 詳細整理後進入共同文章庫；Telegram 介紹能連到詳細正文。

**驗收：** 官方內容保留背景、機制、例子、操作、限制，不因通知長度變短導讀；來源範圍及主題篩選沿用；官方排程不再誤依賴舊 Cron 字串；積壓由背景續跑；重複日次事件不重複生成；主動分享同網址可重用且不被官方相關性篩選淘汰。

### 07：統一雲端預算與 X 重讀費用辨識

**Blocked by:** 02。

**What it delivers:** 管理頁清楚呈現 US$30 月預算、X／Flash／相關雲端用量、預留及未知成本；日內重讀不被錯當每次都是已確認新費用。

**驗收：** 定義可調整的保守重讀風險額度與計價依據；UTC 日去重範圍及台灣月預算分開；Owned Read 只在資格符合時使用；原子預留及未知成本保留；費用暫停不新付費、可繼續已有證據的 Mac 工作／追問與保存內容通知；下月不自動恢復；既有帳目不因搬移再計一次。

### 08：十分鐘局部書籤檢查與每日完整核對

**Blocked by:** 07。

**What it delivers:** 每十分鐘有限頁數檢查新書籤，每日 08:00 完整分頁核對，保存來源並排入處理；網站清楚區分局部檢查與完整成功。

**驗收：** 局部預設一頁上限可設定；局部及全掃各自保存進度，重疊事件不開重複掃描；全掃遇舊 ID 不提早停止；首次基線不被局部掃描誤標完成；舊貼文新收藏可能晚到的語意明示；限流／游標失效／授權與預算暫停可續跑；既有回補確認不被跳過。

### 09：跨入口完成即通知、重複連結與文章更新

**Blocked by:** 02。

**What it delivers:** 官方、書籤及分享都在文章完成後逐篇通知；已完成連結重傳只回既有入口，來源真正增加時更新原文章並通知。

**驗收：** 共同文章／版本去重，不因新 intake 重送完成通知；介紹與全文分開；Telegram 收件確認仍存在；作者二十四小時重查無變更不生成、有補充或缺漏修復才更新並保留舊版／筆記／已讀；等價格式／metadata 變動不重通知；通知失敗只重送保存內容；搬移不觸發歷史通知。

### 10：桌機閱讀雙欄、搜尋篩選與返回導覽

**Blocked by:** 01。

**What it delivers:** 打開網站先看到可搜尋的共同文章列表及閱讀區，按未讀、來源、收件入口和處理狀態找到文章，返回不丟失瀏覽位置；管理有獨立入口。

**驗收：** 沿用現有前端技術；搜尋涵蓋來源全文；URL、分頁及瀏覽器前後進一致；舊文章深層連結可用；失敗／缺漏／費用暫停／等待本機不混淆；狀態更新涵蓋所有入口、不只 X 同步；鍵盤、對比、窄螢幕及程式碼／表格溢位以實際瀏覽器操作驗證。

### 11：可靠筆記與閱讀頁來源／追問整合

**Blocked by:** 05、10。

**What it delivers:** 在新閱讀頁直接保存筆記、標已讀、查看原文與媒體依據及追問歷史，切換文章或更新處理狀態不失去正在做的事。

**驗收：** 筆記自動保存有進度與失敗狀態，斷線保留草稿；快速切換、舊回應及跨分頁衝突不靜默覆寫；來源片段可查核、有效保存期內媒體時間點可跳轉；新舊媒體契約可讀；手動已讀／未讀與文章更新互不重設；追問切換及返回保留正確範圍與歷史。

### 12：代表素材驗收、整合與正式切換交付

**Blocked by:** 03、04、06、08、09、11。

**What it delivers:** 以已完成的各條路徑驗證品質、運行容量、失敗復原及桌機體驗，達標後才啟用本機預設；提供設定、維運及復原說明。

**驗收：** 至少十二組代表素材涵蓋官方長文／程式碼、文字討論、圖片、影片、缺漏、單篇及跨篇追問，逐項對照來源；沒有重大事實錯誤、捏造引用或未標示缺漏；冷啟動／暖機、峰值記憶體、容器共存、context、輸出及排隊時間有真實量測；四類收件到通知完整流程、低預算下本機工作、斷線恢復、舊資料搬移及 UI 操作均有證據；未通過不切換，不把 mock 當品質驗收；正式切換後沒有自動文字 fallback。

## 相依關係說明

- 01 是共同文章身分與相容讀取的基礎，02 與 10 可在它完成後分別開始。
- 02 打通本機文字整條路徑後，03、04、05、06、07、09 可各自實作與驗收；不因修改共同程式而硬加先後依賴。
- 08 必須等 07 修正高頻重讀估算與預算管控，才適合啟用頻繁同步。
- 11 需要新閱讀框架與可持續保存的本機追問，故同時受 10、05 阻擋。
- 12 驗收整體交付，阻擋只列直接前置；其餘由傳遞依賴涵蓋。
