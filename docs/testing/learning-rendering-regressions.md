# 學習流程與閱讀介面回歸驗證

## 修正內容

- 圖片 observation 不需要時間點；影片仍須驗證來源、MM:SS 與長度。混合媒體須保留影片驗證。
- 正文與追問使用 Markdown 解析與 HTML 清理，支援標題、列表、表格、引用與程式碼，移除可執行內容。
- 可辨識的雙重跳脫換行只在正文修復，保護程式碼中的合法字面跳脫。
- 待回補文章提供已保存原文、原始來源連結、單篇啟動與刪除。刪除保留最少網址識別以避免同步重加；手動重新分享可恢復收件。

## 自動與本機驗證

`npm test` 覆蓋圖片與混合媒體驗證、Markdown 渲染與內容清理、換行修復、原文預覽、單篇回補、刪除與同步去重。

`scripts/verify-learning-runtime.mjs` 使用實際 Workers 本機模擬器，驗證打包後的 Markdown 清理、D1 預覽與刪除交易、登入、預算與私人媒體授權。

`scripts/learning-demo.mjs` 提供合成資料，供瀏覽器檢查原文、單篇整理與刪除操作；不讀取真實收藏或呼叫外部模型。

## 正式環境修復原則

修改前將必要備份保存在倉庫外的受限位置。修復已有教材時，優先修正保存內容，保留來源、生成版本與通知紀錄。重試只針對符合錯誤條件的文章，不整批啟動待回補收藏，也不覆寫使用者同時進行的操作。

公開驗證紀錄只保留通用行為與測試方法。真實收藏、收件時間、文章識別碼、帳務、通知與部署識別等操作細節不隨程式碼提交。
